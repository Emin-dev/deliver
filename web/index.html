What this demo can tell you

It checks file size, a container header, browser-reported display dimensions and duration, and a SHA-256 fingerprint. Limits: one file, 64 MiB, up to 16,384 pixels per axis and 24 hours.

Codec, frame rate, HDR, loudness, subtitles, and full playback integrity remain unknown. There’s no encoding, server processing, or delivery to a recipient.

A future owner-hosted mode could add established media probes and encoders. It isn’t running here.
